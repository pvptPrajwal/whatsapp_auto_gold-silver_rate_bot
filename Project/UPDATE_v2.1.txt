GoldSilverBot V2.1 - WhatsApp selector reliability update

What changed:
- The existing fetch_rates() function in app.py was NOT changed.
- WhatsApp Web sender now uses multiple current/fallback selectors.
- Added layout-based fallback detection for search and message boxes.
- Added a WhatsApp search keyboard-shortcut fallback.
- Group matching now checks title, aria-label and visible text.
- Errors now identify whether SEARCH BOX, GROUP, or MESSAGE BOX failed.
- On WhatsApp control failures, screenshot + HTML diagnostics are saved in:
  data/whatsapp_debug/

How to update from the previous ZIP:
1. Stop the old bot.
2. Extract this ZIP to a new folder, OR replace only whatsapp_manager.py.
3. Keep your existing data/whatsapp_profile folder if you want to retain login.
4. Run run.bat.
5. Click Check Session.
6. Click Send Test / Send Now.

If it still fails, send the newest PNG file from data/whatsapp_debug/.
