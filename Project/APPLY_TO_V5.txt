APPLY THIS UPGRADE TO YOUR WORKING V5 FOLDER
============================================

1. Close V5 completely.
2. Make a backup copy of the V5 folder.
3. Copy all files/folders from this upgrade package into the working V5 folder.
4. Choose Replace when Windows asks about existing files.
5. DO NOT delete or replace the V5 data folder.
6. DO NOT delete whatsapp_manager.py. V6 intentionally keeps the working V5 WhatsApp manager unchanged.
7. Run run.bat.

Your existing WhatsApp session/profile and saved settings remain in the V5 data folder.
