GoldSilver Rate Bot V8
======================


1. Run install.bat only for a fresh installation.
2. Run run.bat to open the desktop software.
3. Open Rate Sources.
4. Click Scan Website Rates.
5. Choose the exact Gold rate and Silver rate you want.
6. Click Save Rate Selection.
7. Click Test Selected Rates.
8. Once confirmed, use normal scheduling and WhatsApp sending.

To build a Windows EXE later, run build_desktop_exe.bat.
