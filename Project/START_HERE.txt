GOLDSILVERBOT V6 - START HERE
=============================

1. Keep your working V5 folder as a backup.
2. Extract V6 to a new folder.
3. Run install.bat once.
4. Run run.bat.
5. Connect WhatsApp once if this is a fresh V6 installation.
6. Enter the exact WhatsApp group name, margins and schedule.
7. Click Save Settings, then Start Daily Scheduler.

MOBILE ACCESS
-------------
While V6 is running, the PC dashboard shows:
- Mobile URL (example: http://192.168.1.10:5000)
- 6-digit access PIN

Open that URL from a phone on the same Wi-Fi and enter the PIN.
If Windows blocks the phone connection, right-click allow_mobile_firewall.bat and Run as administrator.

WINDOWS AUTO START
------------------
1. Tick "Automatically start the saved daily schedule when the app starts" in the dashboard.
2. Click Save Settings.
3. Run enable_windows_startup.bat once.

The bot will then launch silently when you sign in to Windows.

IMPORTANT
---------
The website rate-fetching logic is unchanged from the working V5 build.
The mobile dashboard controls the bot running on the PC. The PC must remain powered on and connected to the network.
