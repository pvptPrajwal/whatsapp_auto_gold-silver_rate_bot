GoldSilverBot V5
================

1. Run install.bat ONCE.
2. Run run.bat.
3. Dashboard: http://127.0.0.1:5000
4. First time: click Connect WhatsApp and scan/login in the visible browser.
5. After connection, enter the exact group name and click Send Test / Send Now.

V5 does NOT use Puppeteer/WPPConnect/whatsapp-web.js.
Normal WhatsApp sends use a fully rendered Selenium browser that is hidden/off-screen on Windows.
The existing rate-fetching function has not been changed.
