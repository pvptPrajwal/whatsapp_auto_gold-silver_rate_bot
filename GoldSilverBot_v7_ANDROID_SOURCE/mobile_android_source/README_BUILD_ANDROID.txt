GOLDSILVERBOT V7 - ANDROID APP SOURCE

This is a native Android WebView shell around the same V7 backend.
The host Windows PC must be running GoldSilverBot and the phone must be able to reach the PC network address.

BUILD:
1. Install Android Studio.
2. Open this mobile_android_source folder as a project.
3. Allow Gradle sync to finish.
4. Build > Build App Bundle(s) / APK(s) > Build APK(s).
5. Install the generated APK on the Android phone.
6. On first launch, enter the Mobile address shown on the PC dashboard, e.g. http://192.168.1.10:5000
7. The normal 6-digit Rate Bot mobile PIN page will then appear.

No WhatsApp automation runs on the phone. The phone is a secure controller for the Windows backend, which keeps the proven V5/V6 hidden-Selenium WhatsApp engine.
